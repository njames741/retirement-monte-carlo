# v1.4.0：最低每月生活費與首頁流程

日期：2026-10-18。對應 [Issue #9](https://github.com/njames741/retirement-monte-carlo/issues/9)。

## 使用方式與判定

退休計畫直接設定最低每月生活費，以今天的所選幣種購買力表示，支援千分位及兩位小數。欄位下顯示等值年額、占目前初始生活費的比例；初始生活費低於底線時明示生活費成功率為 0%。

生活費守住要求整段期間資產未耗盡，且每年實付實質支出至少達到最低月額 × 12。仍採年初一次提領、年度判定；月額方便表達生活需求，不代表改為逐月提領。固定金額不會跟著資產、初始提領率變動，也不會強制提領策略增加支出。

模擬總覽、四策略及報酬情境比較共用這筆底線，結果各自顯示完成當次使用的金額。修改參數後，原結果與匯出保留原設定，並提示重新模擬。

## 設定與相容性

- 台幣預設最低每月 80,000；美元預設 2,666.67。切換幣種及重設使用該幣種預設，不依匯率換算。
- 舊設定依「原資產 × 原提領率 × 原比例 / 12」換算一次，四捨五入至兩位小數。舊零底線保持 0，之後調整資產或提領率不再改變月額。新版明確保存的金額（包含 0）優先。
- JSON 保存 `config.minimumMonthlySpending`、幣種及版本；CSV 每列新增最低月額、最低年額及 `today-purchasing-power` 基準欄位。
- 無效金額會阻擋運算，不覆寫上次有效設定。最低金額可以高於初始生活費，此時應回報未達標，不會擅自降低底線。
